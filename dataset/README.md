#Dataset Description

This dataset is used for evaluating a task offloading algorithm between edge and IoT devices.
It records the CPU utilization of both devices at different time slots.

#Columns

time slot – Sequential time intervals (e.g., 1, 2, 3, …).

edge_cpu – CPU usage of the edge device at that time slot.

iot_cpu – CPU usage of the IoT device at that time slot.
